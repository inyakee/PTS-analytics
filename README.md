# PTS Admin Portal — static demo

All analytics are fictional, predefined sample data. No real authentication, visitor tracking, backend, or database exists.

## Pages
- `index.html` — demo login
- `dashboard/index.html` — Overview
- `traffic/index.html` — Traffic Trends
- `performance/index.html` — Page Performance

## Local testing (no server)
Double-click the root `index.html`. The browser will show the actual `.html` filename under `file://`; links work offline. Enter any valid email and nonempty password to proceed. No real password is checked or saved.

## GitHub Pages
Upload the contents of this folder to a GitHub repository. In Settings > Pages, choose Deploy from a branch, select your branch and `/ (root)`, then save. GitHub Pages serves folder index files at extension-free URLs such as `/REPO/dashboard/`, `/REPO/traffic/`, and `/REPO/performance/`. Keep the directory structure intact.

## Security
This is a public demonstration. Login is simulated and pages are not protected. Never put confidential data or actual credentials into this project.
